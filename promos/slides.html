Front end

Three lines
in Twig or Blade

Bring Laravel Echo; Walkie wires the channels.

  • Echo config with the public key only
  • A tiny client: on(), onSection(), here()
{# Twig #} {{ walkie.script() }} walkie.on({ id: {{ entry.id }} }, 'saved', refresh) walkie.onSection('news', 'saved', prepend) walkie.here({ id: {{ entry.id }} }, { here, joining }) {{-- Blade --}} {{ $walkie->script() }}
